# 售电套餐比选小工具

这是一个纯静态网页工具，可直接发布为网络共享页面。用户导入的用电文件只在其浏览器本地处理，不会上传到服务器。

## 发布方法

1. 新建一个代码仓库。
2. 将本文件夹中的全部文件上传到仓库根目录，确保 `index.html` 位于根目录。
3. 在仓库设置中启用 Pages 静态网页服务。
4. 发布来源选择默认分支的根目录并保存。
5. 等待发布完成，使用系统生成的网页地址访问。

请上传“文件夹里面的文件”，不要只上传外层文件夹，也不要解散或改动现有文件之间的相对位置。

## 使用说明

- 支持批量导入 `.xls`、`.xlsx`、`.csv`、`.tsv`。
- 同一企业分散在多个文件时会自动合并。
- 可生成月度24小时分时结果、用电曲线和购电成本分析。
- 下载内容由浏览器本地生成。
- 电价参考数据已随网页打包；后续更新 `tou-data.js` 后重新上传即可发布新数据。

## 文件说明

- `index.html`：网页入口。
- `app.js`、`engine.js`：数据导入、整理和下载逻辑。
- `tou-analysis.js`、`tou-data.js`、`tou-template.js`：电价及套餐分析。
- `styles.css`：页面样式。
- `manifest.webmanifest`、`sw.js`、`icon.svg`：网页安装与离线访问支持。
- `jszip.min.js`：Excel 下载所需组件。
- `JSZIP-LICENSE.md`：第三方组件许可说明。
- `OFFICIAL_UPDATE.md`：电价数据更新说明。

## 更新网页

修改文件后重新上传并覆盖仓库中的同名文件。若浏览器仍显示旧版，可强制刷新或清除该网页缓存后再打开。
